# Giena's Deli

QR ordering menu for Giena's 27th birthday.

- `/` guest ordering (English, Thai, German), live order status, wish wall, ratings, Stack It game
- `/kitchen#k=KEY` kitchen order board (secret key)
- `/board` big-screen Top Chef leaderboard, ratings and wishes

Static site (Preact + htm, no build step). Data lives in Supabase project `giena-deli`.
